## Temporary-runner risk
A remote CI machine's working directory disappears after execution. A manual run button changes dispatch timing, not persistence. Results must be durably saved and restored before later maturity/validation; a fresh empty ledger on every run would lose idempotency and original predictions. Existing388forecasts and their input archives also require migration/bootstrap verification before a remote resolver can evaluate them.

A safe migration must transfer canonical and legacy state, verify every original prediction hash, retain raw snapshots and outcome annotations, and establish one authoritative writer. Independent local/cloud ledgers must not silently issue conflicting payloads for the same deterministic identity. Mutable SQLite checkpoint transfer requires an online backup/verified append-only restore, not copying an active database inconsistently.
